Tópico 01 • Maria Eduarda

🍭 Propriedades Principais 🍭

1. animation-name: Nome dado à animação para conectar o elemento à regra @keyframes.

2. animation-duration: Define o tempo total do início ao fim, medido em segundos (s) ou milissegundos (ms).

3. animation-timing-function: Define o ritmo da animação (ex.: ease para acelerar/desacelerar, linear para velocidade constante).

4. animation-delay: Tempo de espera antes da animação começar após a página carregar ou o elemento aparecer.

5. animation-iteration-count: Controla quantas vezes vai repetir (um número como 3 ou infinite).

Tópico 02 • Victor Juan

🧁 Regras @keyframes 🧁

@keyframes: Regra associada pelo animation-name que contém os seletores de quadro-chave e seus estilos.

from: Equivalente ao valor 0% (início da animação).

to: Equivalente ao valor 100% (fim da animação).

<percentage>: A porcentagem da sequência em que o quadro-chave ocorre.

Comportamento padrão: Se 0%/from ou 100%/to não forem especificados, o navegador usa os estilos originais do elemento. Propriedades não animáveis são ignoradas.

Tópico 03 • Miguel

🍬 Transition vs Animation 🍬

Critério de escolha: A escolha entre CSS Transition e CSS Animation depende diretamente da complexidade do movimento e de como ele é disparado.

CSS Transition: Use para mudanças simples de estado (de A para B), geralmente acionadas por uma interação como o :hover.

CSS Animation: Use para movimentos contínuos, complexos (com várias etapas) ou que precisam rodar sozinhos automaticamente.
